# 💱 Conversor de Moedas

Um conversor de moedas desenvolvido com **HTML, CSS e JavaScript**, criado como parte dos meus estudos em Autoria Web.

O projeto permite informar um valor em reais (BRL) e realizar a conversão para dólar (USD).

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
